# Подключение ESP32 к бойлеру — пошагово

ESP32 — маленькая плата у бойлера, общается с ним по Bluetooth и отдаёт данные в
вашу Wi-Fi. Сначала прошейте плату (`flashing-windows11.ua.md` и др.), затем сюда.

## Шаг 1. Отключите штатное приложение

Бойлер держит **только одно** Bluetooth-соединение. Закройте фирменное
приложение Drazice / выключите в нём Bluetooth, иначе ESP32 не увидит бойлер.

## Шаг 2. Узнайте Bluetooth-адрес бойлера (MAC)

Бойлер виден в эфире только когда к нему никто не подключён. Адрес
`AA:BB:CC:DD:EE:FF` впишите в `firmware/secrets.yaml` (`boiler_ble_mac`).

## Шаг 3. Найдите ESP32 в сети

Вкладка **«Устройства»**: если не знаете IP — «Найти ESP32 в сети» (базовый IP,
напр. `172.16.0.1`). Устройство с меткой **«Это наш бойлер»** и есть ваша ESP32.
Впишите его IP, логин и пароль (из `secrets.yaml`), сохраните. Рекомендуется
закрепить адрес на роутере (DHCP reservation).

## Шаг 4. Сопряжение по PIN

На экране бойлера активируйте добавление устройства (состояние станет
**«Require PIN»**). Пока горит запрос (~20 с), введите PIN с экрана в поле
«PIN сопряжения» и нажмите «Отправить PIN». PIN **не сохраняется**. Состояние
**Connected** — готово.

## Шаг 5. Проверка

Перезагрузите ESP32 — сопряжение сохранится (PIN вводить не нужно). «Освободить
BLE» → штатное приложение может подключиться; «Подключить BLE снова» → возврат к
мониторингу.

## Шаг 6. Сначала только наблюдение

Оставьте режим **только мониторинг** минимум на сутки. Проверьте адекватность
температур и определения нагрева. Потом — ручное управление и позже автоматика.
