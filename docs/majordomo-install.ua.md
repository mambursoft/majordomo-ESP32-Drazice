# Встановлення модуля в MajorDoMo

## Передумови (перевірити, нічого не ламаючи)

Перед змінами на робочому сервері перевірте (read-only): версії PHP CLI **і**
FPM (можуть різнитися), розширення `curl` і `json`, права на теку модулів,
доступ до БД через `~/.my.cnf`. Пароль БД **не** друкуйте в логах.

## Встановлення пакета

```bash
# з бекапом: збережіть поточні теки модуля/конфіги перед розгортанням
sudo tar -xzf drazice_smart.tgz -C /var/www/html/
```

Пакет кладе:
- `modules/drazice_smart/` — клас, lib, шаблони, db_install, languages;
- `languages/drazice_smart_*.php` — локалізація (UA/RU/EN);
- `scripts/cycle_drazice_smart.php` — цикл-воркер.

Відкрийте модуль у MajorDoMo. При першому запуску він:
- створить таблиці `drazice_telemetry`, `drazice_decisions`, `drazice_commands`,
  `drazice_presence` (міграції re-safe: лише додають, не видаляють історію);
- запише безпечні дефолти (моніторинг, автоматика вимкнена, dry-run).

## Перевірка синтаксису під PHP 7.3

```bash
find /var/www/html/modules/drazice_smart -name '*.php' -exec php -l {} \;
php /var/www/html/modules/drazice_smart/../../tests/run.php   # 103 тести
```

## Цикл-воркер

Зареєструйте `scripts/cycle_drazice_smart.php` у штатному планувальнику MajorDoMo
(cron/cycle). Скрипт:
- робить один обмежений крок за виклик (snapshot → рішення → за потреби запис);
- має файловий лок (без паралельних запусків) і self-throttle за інтервалом
  опитування; **без** нескінченного циклу і довгих sleep.

Не створюйте окремий systemd-воркер-дубль, якщо вже реєструєте у циклі MDM.

## Порядок безпечного введення

1. Backup → розгортання → `php -l` / тести.
2. Вкладка «Пристрої»: знайти ESP32, вказати доступ.
3. Пейрінг (`pairing.ua.md`).
4. Доба моніторингу (автоматика вимкнена).
5. Вкладка «Енергополітика» / «Тариф»: погодити параметри; прив'язати SOC і
   (за наявності) прогноз.
6. Ручне керування з readback.
7. Лише після цього — увімкнути автоматику (окреме свідоме рішення).

## Nginx

Нічого не змінюйте без потреби. Якщо треба: backup → `sudo nginx -t` → лише при
успіху `sudo systemctl reload nginx`. Збережіть `$without_megad`, LAN-винятки,
маршрути MegaD і TV. ESP32 **не** відкривати через публічний 80/443.
