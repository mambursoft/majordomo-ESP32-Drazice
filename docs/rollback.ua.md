# Відкат (rollback)

Відкат — безпечний і частковий. Не відновлюйте всю БД поверх актуальних даних
розумного будинку.

## Модуль MajorDoMo

1. **Вимкніть автоматику** у модулі (вкладка «Керування» → «Вимкнути автоматику»)
   і увімкніть dry-run. Це зупиняє будь-які записи в бойлер негайно.
2. Зупиніть **лише** цикл-воркер модуля (не чіпайте інші воркери MDM).
3. За потреби відновіть попередні файли модуля з бекапа, зробленого перед
   розгортанням. Таблиці `drazice_*` — append-only; видаляти їх не обов'язково.
   Якщо все ж видаляєте — лише ці таблиці, не схему MDM.
4. Бойлер переведіть у погоджений ручний режим зі штатного екрана/застосунку.

## Прошивка ESP32

- Невдале OTA: USB → затиснути BOOT → записати перевірений `firmware.factory.bin`
  (`tools/flash/flash.py write ...`). Після повного erase може знадобитися
  повторний пейрінг (PIN).
- **Не** відновлюйте випадковий NVS-дамп на іншу partition table чи інший
  пристрій без перевірки.
- Backup `backup-private.bin` зберігайте приватно (Wi-Fi/UID).

## Секрети

За підозри на витік — змініть Wi-Fi/HTTP/OTA паролі в `secrets.yaml`, перепрошийте,
оновіть доступ у модулі.

## Nginx / мережа

Нічого з Nginx відкочувати не потрібно, бо модуль його не змінює. Якщо ви вручну
щось міняли — `sudo nginx -t` перед `reload`, збережіть `$without_megad` і
LAN-винятки.
