# Откат (rollback)

Откат безопасный и частичный. Не восстанавливайте всю БД поверх актуальных данных
умного дома.

## Модуль MajorDoMo

1. **Выключите автоматику** (вкладка «Управление») и включите dry-run — это
   немедленно останавливает любые записи в бойлер.
2. Остановите **только** cycle-worker модуля (не трогайте другие воркеры).
3. При необходимости восстановите прежние файлы модуля из бэкапа. Таблицы
   `drazice_*` — append-only; удалять не обязательно. Если удаляете — только их,
   не схему MDM.
4. Бойлер переведите в согласованный ручной режим со штатного экрана/приложения.

## Прошивка ESP32

- Неудачное OTA: USB → зажать BOOT → записать проверенный `firmware.factory.bin`.
  После полного erase может понадобиться повторное сопряжение (PIN).
- Не восстанавливайте случайный NVS-дамп на другую partition table/устройство.
- Backup `backup-private.bin` храните приватно (Wi-Fi/UID).

## Секреты

При подозрении на утечку — смените Wi-Fi/HTTP/OTA пароли в `secrets.yaml`,
перепрошейте, обновите доступ в модуле.

## Nginx / сеть

Откатывать Nginx не нужно — модуль его не меняет.
