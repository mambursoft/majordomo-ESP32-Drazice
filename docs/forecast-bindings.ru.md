# Привязка прогноза солнечной генерации

Модуль бойлера **не** содержит своего движка прогноза — он только **читает**
свойства MajorDoMo, которые заполняет другой модуль (напр. соседний Solar
Planner) или ваш скрипт. Прогноз **необязателен**: солнечный избыток
определяется напрямую по SOC батареи.

## Как привязать (вкладка «Источники прогноза»)

1. «Найти свойства прогноза» — поиск по словам `solar`, `forecast`, `pv`,
   `solcast`, `meteo`, `прогноз`, `солнце`.
2. Выберите свойства вручную: «остаток сегодня» (кВт·ч), «завтра» (кВт·ч),
   «время обновления» (UTC unix), «провайдер». Сохраните.

## Правила

- Не привязано / значение отсутствует → **«нет данных»**, а не `0`. Ноль ≠
  отсутствие.
- Устаревший прогноз помечается `stale`, используется осторожно.
- Прогноз ≠ реальный избыток: `завтра = 30 кВт·ч` не значит, что сейчас можно
  включать бойлер. Режим «солнечный избыток» использует **SOC сейчас**.
- Не суммируйте прогнозы разных провайдеров. Не берите суточный total как
  «остаток сегодня».
