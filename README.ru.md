# MajorDoMo ↔ ESP32 ↔ Drazice SMART

Мониторинг и безопасное управление бойлерами **Drazice SMART** (основная модель —
OKHE 125 SMART) через **Wi-Fi → ESP32 → BLE** для [MajorDoMo](https://github.com/sergejey/majordomo).
Без обязательного Home Assistant и без брокера MQTT.

> **Безопасно по умолчанию.** Модуль стартует в режиме **только мониторинг**
> (`dry-run`). Автоматическое управление выключено, пока вы явно его не включите
> и не подтвердите параметры. BLE **не является** каналом аварийного отключения:
> потеря связи не гасит нагрев.

Языки интерфейса: **украинский** (основной), English, русский.
Документация: на украинском и русском (`docs/`).

## Что это и для кого

Вы — владелец дома с бойлером Drazice OKHE 125 SMART и системой MajorDoMo на
Raspberry Pi. Вы **никогда не работали с ESP32**. Этот проект даёт:

1. **Прошивку ESPHome** для платы WeAct Studio ESP32-D0WD-V3, которая
   подключается к бойлеру по Bluetooth и отдаёт его состояние в локальную сеть
   по HTTP.
2. **Модуль MajorDoMo `drazice_smart`** — панель управления с понятными
   пояснениями, безопасными значениями по умолчанию и мастерами настройки.
3. **Детерминированный планировщик** нагрева: ночной тариф (23:00–07:00),
   солнечный избыток (когда батарея заряжена на 100%), ограничение длительной
   нагрузки.
4. Опциональное **определение присутствия** в туалете по Wi-Fi/BLE смартфона с
   уведомлением на колонку (по умолчанию выключено, честно документированные
   ограничения).

## Безопасность прежде всего

- Прошивка **не коммутирует** ТЭН бойлера. Никаких реле на силовых клеммах.
  Штатные защиты (термостат, термозащита, заземление, УЗО) остаются
  нетронутыми.
- Снижение температуры или смена режима **не гарантирует** физического
  отключения нагрева. Подробно — [`docs/electrical-safety.ru.md`](docs/electrical-safety.ru.md).
- Секреты никогда не попадают в Git. См. [`firmware/secrets.example.yaml`](firmware/secrets.example.yaml).
